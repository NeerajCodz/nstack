Create a test plan for: $ARGUMENTS

Include:
1. Unit tests (what to test, edge cases, mocks needed)
2. Integration tests (component interactions, API contracts)
3. End-to-end tests (critical user flows)
4. Manual QA checklist
5. Edge cases and boundary conditions
6. Error scenarios
7. Performance test criteria
8. Regression risks
9. Test data setup
10. Commands to run

Format as actionable checklist with:
- Test name
- What it verifies
- Priority (P0/P1/P2)
- Type (unit/integration/e2e/manual)
- Estimated effort
